SoundCloud widget — where the layout changes

The same profile, same params, only the BOX changes. Read it for the width at which artwork appears and the height at which the classic player turns into the artwork player.

Measured on an iPhone 17 Pro (402pt wide), 2026-08-06. WIDTH is the gate, not height: artwork appears somewhere between 341px (no) and 351px (yes), and once you are past it the side-by-side layout works at as little as 120px tall — SHORTER than the 166px the app uses today, and with artwork. So the artwork is not bought with height; it is bought with width. Note this threshold is in CSS px, so a wider phone crosses it where a narrower one does not — which is why the artist page shows artwork on some devices and not others.
